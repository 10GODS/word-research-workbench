# Contact

## Collaboration

For engineering, testing, documentation, or research collaboration, open a GitHub issue with the title prefix **[Collaboration]** and briefly describe:

- your GitHub background or relevant experience,
- the area you want to help with,
- your Windows / Microsoft Word test environment if relevant,
- whether you are interested in code, QA, research workflow, UI/UX, privacy/security, or performance testing.

## Sponsorship / research partnership

For sponsorship, pilot studies, academic partnerships, infrastructure support, testing hardware, research-software engineering, or institutional collaboration, open a GitHub issue with the title prefix **[Partnership]**.

If the discussion becomes sensitive, do not post private details in the public issue. Use the issue only to request direct contact from the repository owner.
