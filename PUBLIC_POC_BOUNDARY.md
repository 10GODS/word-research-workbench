# Public POC Boundary

This repository is a **public proof of concept** for a Word-native research workbench. It is intentionally incomplete.

## Public here

- Product direction and user workflow
- Mock/demo task-pane experience
- Public-beta screenshots and documentation
- Collaboration and sponsorship information
- High-level descriptions of local/offline processing, scholarly lookup, citation workflow, research-integrity support, and optional web workspaces

## Not published here

- Production Microsoft Word add-in source
- Model weights/checkpoints
- Private prompts, transformation rules, evaluation heuristics, or unreleased research logic
- API keys, credentials, certificates, signing material, or local user data
- Full citation/retrieval backend
- Private installer/updater infrastructure
- Manuscripts, logs, caches, local databases, or generated user content

## Why this boundary exists

The repository is meant to make the concept understandable, reviewable, and discoverable while keeping unpublished implementation details and user data out of a public codebase.

Public visibility of this POC does not imply that unpublished components are open source or licensed for reuse.

## Security note

Never submit real manuscript content, credentials, API keys, unpublished model assets, or confidential research data in public issues or pull requests.
