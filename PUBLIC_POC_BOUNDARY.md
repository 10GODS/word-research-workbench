# Public POC Boundary

This repository is a **public proof of concept and collaboration surface** for Author Focus / Word Research Workbench. It is intentionally incomplete.

## Public here

- Product direction and researcher workflow
- Mock/demo task-pane experience
- Public-beta screenshots and documentation
- Science-first UX principles
- High-level local/offline AI architecture
- Scholarly lookup and citation-verification concepts
- Research-integrity and evidence-workflow concepts
- High-level Python/Jupyter Research Lab direction
- High-level Google Earth Engine and GIS workflow direction
- Roadmap, citation metadata, collaboration, and sponsorship information

## Not published here

- Production Microsoft Word add-in source
- Private Author Focus v4.3 application package
- Model weights/checkpoints
- Private prompts, transformation rules, evaluation heuristics, or unreleased research logic
- API keys, credentials, certificates, tokens, or signing material
- Full private citation/retrieval backend
- Private Python/Jupyter execution backend implementation
- Private GEE/GIS skill implementation
- Production installer/updater infrastructure
- Manuscripts, notebooks, logs, caches, databases, research data, or generated user content

## Why this boundary exists

The repository is intended to make the concept understandable, reviewable, citable, and discoverable while keeping unpublished implementation details and user data out of a public codebase.

This boundary also allows the project to document research-software ideas, workflows, and collaboration opportunities without accidentally publishing credentials, unpublished scientific material, private model assets, or code that is still being evaluated.

Public visibility of this POC does not imply that unpublished components are open source or licensed for reuse.

## Scientific claims and integrity

Automated checks described in this repository are screening and workflow tools. They do not prove that:

- a manuscript is scientifically correct,
- research data are authentic,
- a statistical analysis is valid,
- a source proves a claim,
- or text was written by a human or AI.

Researcher review remains required.

## Security note

Never submit real unpublished manuscript content, private research data, credentials, API keys, unpublished model assets, or confidential implementation details in public issues or pull requests.
