# Contributing

Thanks for your interest in the Word Research Workbench public beta.

## Good contribution areas

- Microsoft Word / Office.js task-pane UX
- Office Dialog API and WebView2 behavior
- Windows installation and update reliability
- CPU-first local inference and Intel OpenVINO testing
- Citation and reference workflow UX
- Accessibility and keyboard navigation
- Privacy/security review
- QA across Microsoft 365 / Word versions
- Documentation and reproducible bug reports

## Before contributing

1. Check existing issues first.
2. Open or claim a focused issue before doing substantial work.
3. Use a feature branch rather than committing directly to `main`.
4. Keep pull requests narrow and explain how you tested the change.
5. Never include API keys, credentials, certificates, real manuscripts, private research data, model weights, or unpublished production internals.

## Public POC boundary

This repository intentionally does not contain the full production implementation. Please read [`PUBLIC_POC_BOUNDARY.md`](PUBLIC_POC_BOUNDARY.md) before proposing changes.

## Pull request checklist

- [ ] Change is limited to the public-beta scope
- [ ] No secrets or private research material are included
- [ ] User-facing behavior is described clearly
- [ ] Relevant manual testing is documented
- [ ] Screenshots use non-sensitive content

## Collaboration

For deeper engineering collaboration, see [`COLLABORATION.md`](COLLABORATION.md). Access to unpublished/private components is not implied by a public contribution and is considered separately.
