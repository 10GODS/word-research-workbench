# Security Policy

## Public beta scope

This repository is a public proof of concept. Do **not** post secrets, unpublished manuscripts, private research data, API keys, certificates, model checkpoints, local databases, or production-only implementation details in issues, pull requests, discussions, or screenshots.

## Reporting a security or privacy concern

For a non-sensitive concern, open a GitHub issue and prefix the title with **[Security]** or **[Privacy]**.

For a concern that would require publishing credentials, exploit details, personal data, or confidential research information, **do not post the details publicly**. Instead, open a minimal issue requesting private contact from the repository owner without including the sensitive material.

## Supported status

The project is currently an experimental public beta / proof of concept. Security hardening, packaging, signing, update infrastructure, and cross-version Microsoft Word testing are ongoing.

## Data-handling principle

The product direction is local-first: manuscript text and research material should remain on the user's machine unless a user intentionally invokes an external service. Public demo material should always use non-sensitive or synthetic examples.
