# Roadmap

## v0.1 — Public proof of concept

- Present the Word-native research-workbench concept
- Show local-first processing, scholarly lookup, citation workflow, notes, and research-integrity directions
- Invite focused collaborators and research partners

## v0.2 — Beta reliability

- Improve installation and upgrade reliability
- Add clearer diagnostics and refresh/restart handling
- Test across more Windows and Microsoft Word / Microsoft 365 versions
- Improve keyboard navigation and accessibility

## v0.3 — Local inference evaluation

- Benchmark CPU and Intel OpenVINO paths
- Measure latency, memory use, and factual-surface preservation
- Test representative academic/research paragraphs
- Document failure cases instead of relying on detector scores

## v0.4 — Citation and evidence workflow

- Refine manual scholarly verification
- Improve citation/reference insertion and provenance-aware checks
- Improve researcher approval and rollback behavior

## v0.5 — Wider beta

- Structured beta feedback
- Sanitized diagnostic export
- Broader QA and reproducibility testing
- Institutional / academic pilot discussions

## v1.0 planning

A stable release would require a clear licensing model, packaging/signing strategy, update mechanism, privacy/security review, support expectations, and an explicit public/private source boundary.
