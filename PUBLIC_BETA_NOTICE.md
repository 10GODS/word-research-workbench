# Public Beta Notice

This repository is public and contains an early proof of concept for the **Word Research Workbench**.

The public repository is intentionally limited to demonstrable workflow, interface concepts, documentation, collaboration material, and selected screenshots. It does not publish the complete production system.

The following remain outside this public repository unless explicitly released later:

- production Word add-in source,
- model weights and private inference assets,
- private prompts and transformation rules,
- unpublished research-integrity logic,
- credentials, certificates, and signing material,
- private installer/update infrastructure,
- user manuscripts, logs, local databases, and generated content.

Features, architecture, names, and APIs may change substantially before a stable release.

See [`PUBLIC_POC_BOUNDARY.md`](PUBLIC_POC_BOUNDARY.md) for the current public/private boundary.
