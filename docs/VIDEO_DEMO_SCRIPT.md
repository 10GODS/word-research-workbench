# 90-Second POC Demo Script

## 0–15 s — Problem

Show Microsoft Word with the research task pane.

Narration: “Research writing usually means jumping between Word, browser tabs, citation tools, notes, and local utilities. This private beta explores bringing those workflows into one Word-centered workspace.”

## 15–35 s — Three browser workspaces

Click the three browser cards in sequence.

Narration: “The concept provides three in-Word web workspaces: a writing/research surface, a second AI/research surface, and Google Scholar for manual scholarly lookup. The production beta uses Office web dialogs; this repository shows the interaction pattern only.”

## 35–55 s — Citation flow

Enter a mock article title in Scholar Workspace, then paste a sample in-text citation and reference.

Narration: “Scholar lookup remains manual. The researcher verifies the source, then inserts the citation and reference into Word without hidden scraping.”

## 55–70 s — Notepad

Open Notepad, type a short note, and click Save.

Narration: “A deliberately minimal notepad keeps quick working notes without turning the add-in into another document manager.”

## 70–85 s — Local processing

Open Local Processing.

Narration: “The architecture also has a CPU-first offline processing slot for privacy-sensitive text work. Model assets and private implementation details are excluded from this proof of concept.”

## 85–90 s — Close

Narration: “This is a private beta seeking collaborators for Office integration, Windows testing, local inference optimization, research workflow design, and sponsorship for pilot development.”
