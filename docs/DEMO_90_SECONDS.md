# 90-Second Author Focus Demo

## Goal

Show one complete research workflow in under 90 seconds:

**manuscript issue → evidence check → analysis verification → corrected Word result**

The demo should prove that Author Focus is not merely a writing assistant. It connects manuscript text to citations, analysis, and scientific evidence.

## Recommended demo scenario

Use a small, non-confidential geospatial example with:

- one Microsoft Word manuscript,
- one Jupyter notebook,
- one CSV/table,
- one generated figure,
- and one citation with verifiable metadata.

A vegetation/LST example is ideal because the relationship between data, analysis, figure, statistics, and manuscript text is visually easy to understand.

## Storyboard

### 0–10 s — Start inside Microsoft Word

Show Author Focus beside a manuscript.

On-screen message:

> One research workspace inside Microsoft Word.

Briefly show the main actions:

- Check complete manuscript
- Manual corrections
- Python Lab
- Evidence

Do not linger on settings.

### 10–25 s — One-click scientific review

Run or demonstrate the unified review.

Show findings such as:

- one citation requiring verification,
- one numerical inconsistency,
- one figure/table reference issue,
- and one writing issue.

On-screen message:

> Review writing, citations, evidence, statistics and structure together.

### 25–40 s — Inspect a numerical conflict

Select a sentence such as:

> Mean NDVI increased from 0.31 to 0.49.

Author Focus shows that the linked analysis output reports:

> 2020 = 0.31  
> 2025 = 0.46

Highlight:

> Numerical conflict detected.

This is the key moment of the demo.

### 40–55 s — Verify with Jupyter/Python

Open the linked notebook/evidence view.

Show:

- notebook name,
- relevant cell,
- input data,
- executed value,
- and provenance record.

On-screen message:

> Trace manuscript claims back to the analysis that produced them.

Do not show long code unless briefly expanding an “Advanced” panel.

### 55–68 s — Correct in Word

Return to the correction queue.

Suggested correction:

> Mean NDVI increased from 0.31 in 2020 to 0.46 in 2025.

Show:

- source value,
- proposed correction,
- Accept / Reject / Edit.

Accept the correction with Track Changes visible.

### 68–80 s — Citation verification

Open one citation result.

Show:

- DOI matched,
- title/authors/year matched,
- publication status,
- evidence status.

On-screen message:

> Verify the source, not just the citation format.

### 80–90 s — Finish with product identity

Final frame:

> **Author Focus Research Lab**  
> Data → Analysis → Evidence → Manuscript  
> **Inside Microsoft Word**

Secondary line:

> Local-first. Researcher-controlled. Science-first.

## Recording rules

- Use a clean example project, never unpublished/confidential data.
- Keep the Word document readable at normal zoom.
- Avoid terminal windows unless absolutely necessary.
- Prefer one continuous story over a feature montage.
- Do not use AI-detector scores as the headline.
- Do not claim scientific correctness from an automated score.
- Keep all edits visibly researcher-approved.

## Suggested video title

**Author Focus Research Lab: Verify Research Evidence Inside Microsoft Word**

Alternative:

**From Jupyter Analysis to Verified Manuscript — Inside Microsoft Word**

## Suggested description

Author Focus is a local-first Microsoft Word research-workbench concept connecting academic writing, citation verification, research-integrity review, Python/Jupyter analysis, and evidence-linked manuscript workflows. This demo shows how a quantitative statement can be traced back to its analysis output and corrected with researcher approval.
