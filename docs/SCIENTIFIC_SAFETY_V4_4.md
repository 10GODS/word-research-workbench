# Scientific safety controls — v4.4 direction

This page documents safety principles for the private Author Focus package. It is not a guarantee that every workflow is scientifically valid.

## Keep evidence types distinct

- SOURCE FACT — directly observed in a source or dataset record.
- COMPUTED RESULT — present in an output from an executed workflow.
- AUTHOR INTERPRETATION — an author's explanation of what evidence means.
- AI SUGGESTION — generated plan, method or wording that requires review.
- EXTERNAL LITERATURE — published evidence that must be identified and read.

## Researcher approval and protected content

Code generation does not imply execution. Researchers explicitly start code/notebook execution after reviewing the code. Scientifically meaningful manuscript changes involving numbers, statistics, citations, uncertainty, causal language, methods, terminology or interpretation remain reviewable. A plan is a proposal until the author approves it.

## Statistical interpretation

Recommendations must explain the target question, assumptions, interpretation and limitations. Spatial or temporal dependence, confounding, multiple testing, missingness and study design matter. Correlation or observational association is not causation. A nonsignificant result is not proof of no effect or equivalence.

## Evidence states

VERIFIED, REVIEW, CONFLICT and NO EVIDENCE are traceability/review labels, not truth scores or confidence estimates. A recorded link states that an evidence relationship is proposed or documented; it does not authenticate the source, data or claim.

## Methods and Results

Methods should reflect work actually executed. Generated code, a proposed plan or a notebook that has not been run is not execution evidence. Results should use values traceable to saved outputs. Missing evidence should be reported as missing. A text or numeric match alone cannot establish correct units, context, statistical validity or provenance.

## Privacy and external services

Local-first operation remains available. Remote AI and scholarly services are optional and should be disclosed when used. Private manuscripts and research data should not be placed in public issues or repositories.

## Validation limits

Automated review is screening, not proof of validity, authenticity, misconduct or authorship. Windows Word, Microsoft 365, authenticated Earth Engine and live external-provider behavior require tests in those environments.
