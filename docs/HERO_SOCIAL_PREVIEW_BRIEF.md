# GitHub Hero and Social Preview Brief

## Objective

Make a visitor understand the project in roughly five seconds.

The visual should communicate:

**Microsoft Word + scientific evidence + Python/Jupyter + geospatial analysis**

without looking like a generic chatbot product.

## Primary headline

**Author Focus Research Lab**

## Primary subheadline

**From data and analysis to a verified manuscript — inside Microsoft Word.**

Alternative:

**Data → Analysis → Evidence → Manuscript**

## Supporting line

**Local-first · Researcher-controlled · Science-first**

## Recommended hero composition

Use one clean 16:9 image.

### Left side

Microsoft Word manuscript with:

- one highlighted quantitative sentence,
- one citation,
- one visible figure/table reference.

### Center

Author Focus review panel showing a small number of meaningful statuses:

- Citation verified
- Numerical conflict
- Evidence linked
- Manual review required

Do not show dozens of tiny controls.

### Right side

A restrained research-evidence panel containing:

- Jupyter notebook icon/label,
- one small plot or map,
- one evidence arrow pointing back to the manuscript claim.

## Text hierarchy

1. Author Focus Research Lab
2. Data → Analysis → Evidence → Manuscript
3. Local-first · Researcher-controlled · Science-first

Avoid paragraphs inside the visual.

## Recommended GitHub social-preview size

Prepare the final asset at a wide social-preview ratio suitable for GitHub sharing, with enough safe margin that text is not cropped in link previews.

## Visual style

- clean academic/research-software look,
- Word interface should remain recognizable,
- use real product screenshots where possible,
- use one accent colour consistently,
- avoid neon “AI” aesthetics,
- avoid robot imagery,
- avoid brain/circuit stock graphics,
- avoid detector percentages,
- avoid claiming “100% accurate” or “AI-proof.”

## Thumbnail rule

If the image is viewed very small, these three things must still be readable:

**Author Focus**  
**Research Lab**  
**Data → Evidence → Manuscript**

## Suggested alt text

> Author Focus Research Lab shown beside a Microsoft Word manuscript, linking citation and numerical review findings to Jupyter analysis and geospatial evidence.

## Video thumbnail

Use the same visual identity.

Recommended thumbnail title:

**VERIFY RESEARCH INSIDE WORD**

Small supporting line:

**Jupyter · Citations · Evidence · GIS**

## What increases perceived value

Show evidence traceability rather than a feature grid.

A screenshot proving:

> manuscript value → actual notebook result

is more valuable than a screenshot containing twenty AI buttons.
